# 🚗 CarDekho Car Price Prediction

## 🎯 Project Objective

To build an end-to-end Machine Learning system that predicts the selling price of used cars based on their vehicle characteristics and evaluates different regression models to select a suitable model for prediction.

## 🔄 Workflow

Data Preparation → EDA → Feature Engineering → Model Training → Evaluation → Model Comparison → Model Selection → Flask Deployment

## 🤖 Models

- Linear Regression
- Ridge Regression
- Lasso Regression
- SVR
- Decision Tree Regressor
- Random Forest Regressor

## 🛠️ Tech Stack

Python • Pandas • NumPy • Matplotlib • Seaborn • Scikit-learn • Flask • Jupyter Notebook

## 📌 Key Concepts

- Exploratory Data Analysis
- Data Preprocessing
- Feature Engineering
- Regression
- Model Evaluation & Selection
- Hyperparameter Tuning
- Model Serialization
- ML Deployment
